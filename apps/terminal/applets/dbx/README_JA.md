## DBX

軽量なクロスプラットフォームデータベースクライアント。MySQL、MariaDB、PostgreSQL、Oracle、SQLServer、達夢、ClickHouse、MongoDB、Redis に対応しています。

### 構成

アプリケーションとドライバは 1 つのインストールパッケージにまとめられ、`C:\Program Files\DBX` に展開されます:

- アプリケーション：`C:\Program Files\DBX\DBX.exe`、グローバル環境変数 `DBX_HOME` で別のインストール先を指定できます
- ドライバ：`C:\Program Files\DBX\agents`、JRE 21 と Oracle、達夢のドライバを含みます。グローバル環境変数 `DBX_DRIVERS_HOME` で別のディレクトリを指定できます

MySQL、MariaDB、PostgreSQL、SQLServer、ClickHouse、MongoDB、Redis は DBX 内蔵ドライバを使用するため、追加コンポーネントは不要です。Oracle と達夢は接続時にインストールディレクトリから現在のセッションユーザーのディレクトリへドライバが自動コピーされ、JRE はインストールディレクトリのものをそのまま使用します。いずれもインターネット接続は不要です。

### 補足

- グローバル環境変数 `DBX_CLEAN_HOME_AT_CLOSE` で終了時にアプリケーションデータを削除するかを制御します。既定値は `true` です
- ドライバとアプリケーションのバージョンは対応している必要があり、同一のインストールパッケージで配布されます
- インストールパッケージは JumpServer のダウンロードサイトから配信されます。アプリケーション発行サーバーは JumpServer に到達できれば十分で、インターネット接続は不要です
- ドライバパッケージには DB2 ドライバも含まれますが、DBX 0.6.17 の接続ディープリンクは db2 タイプに未対応のため、サポートプロトコルには含めていません
- 接続 URL にパスワードは含めません。アプリが接続ダイアログへ入力し「パスワードを保存」を外すため、コマンドラインにも接続設定にも残りません。入力に失敗した場合はパスワード付きの接続 URL にフォールバックします
- 画面の言語はアプリケーション発行サーバーの Windows 言語に関係なく、JumpServer で設定したユーザーの言語に従います。DBX に対応する言語がない場合は英語になります
- Oracle を sysdba で接続するかは接続オプション use_sysdba に従い、オプションがない場合は特権アカウントかどうかで判断します
- SSL 接続は未対応です
